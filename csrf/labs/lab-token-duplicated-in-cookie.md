# Lab: CSRF where token is duplicated in cookie

**Official lab:** [Lab: CSRF where token is duplicated in cookie](https://portswigger.net/web-security/csrf/bypassing-token-validation/lab-token-duplicated-in-cookie)

## Lab idea

This challenge covers the double-submit-cookie approach to CSRF protection. It practices evaluating whether the submitted token and cookie comparison provides a sound defense when the application also has a way to influence browser cookies.
