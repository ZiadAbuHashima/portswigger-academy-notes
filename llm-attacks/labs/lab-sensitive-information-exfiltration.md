# Lab: Exploiting AI agents to exfiltrate sensitive information

**Official lab:** [PortSwigger Web Security Academy](https://portswigger.net/web-security/llm-attacks/ai-powered-scanner-vulnerabilities/lab-sensitive-information-exfiltration)

**Lab idea:** This challenge explores indirect prompt injection against an AI scanner that can access sensitive account data while auditing a site. It practices assessing whether untrusted content can influence an agent to disclose information it can access on behalf of another user.
