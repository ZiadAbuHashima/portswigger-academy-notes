# Lab: Exploiting AI agents to perform destructive actions

**Official lab:** [PortSwigger Web Security Academy](https://portswigger.net/web-security/llm-attacks/ai-powered-scanner-vulnerabilities/lab-indirect-prompt-injection-via-ai-powered-scan)

**Lab idea:** An AI-powered scanner examines user-generated content while holding authenticated access. The challenge illustrates how indirect prompt injection in that content can steer the agent toward an unintended destructive action, and practices evaluating an agent’s privileges and trust boundaries.

## Vulnerability in brief
**Web LLM attacks** are security risks that arise when websites integrate large language models (LLMs) with user input, application data, or tools such as APIs. This is a broad attack category, not one single vulnerability class. An LLM can expose data or invoke capabilities that an attacker cannot access directly, so an unsafe integration can make the model an intermediary to protected systems. [Official topic](https://portswigger.net/web-security/llm-attacks)
