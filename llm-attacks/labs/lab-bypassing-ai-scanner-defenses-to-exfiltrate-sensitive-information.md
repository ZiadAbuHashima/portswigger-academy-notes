# Lab: Bypassing AI scanner defenses to exfiltrate sensitive information

**Official lab:** [PortSwigger Web Security Academy](https://portswigger.net/web-security/llm-attacks/ai-powered-scanner-vulnerabilities/lab-bypassing-ai-scanner-defenses-to-exfiltrate-sensitive-information)

**Lab idea:** This challenge focuses on how indirect prompt injection can influence an AI-powered scanner that has access to sensitive user data, even when the scanner includes defenses. It practices assessing whether untrusted site content can steer an agent toward exposing data beyond its intended use.
